# Procédure : dérive du temps de cycle

S'applique quand le temps de cycle mesuré s'écarte de plus de 5 % de la consigne.

1. Relever le temps de cycle sur dix cycles consécutifs.
2. Vérifier la température du moule et le temps de refroidissement.
3. Faire reprendre les paramètres par le régleur.
4. Si la dérive revient dans la journée : créer une demande d'intervention maintenance, priorité normale.
