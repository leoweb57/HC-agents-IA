# Diagnostic d'un arrêt machine

À ÉCRIRE. La méthode, étape par étape, comme vous l'expliqueriez à un nouveau collègue :

1. Quel outil appeler pour trouver l'arrêt, et quoi retenir.
2. Comment savoir si c'est déjà arrivé (l'historique, sur 30 jours).
3. Comment savoir si la qualité a été touchée (les contrôles de l'ordre de fabrication).
4. Quelle procédure lire, selon la cause. Les deux procédures sont dans le dossier procedures/ de ce skill.

## Format de la réponse

À ÉCRIRE. Le format que vous voulez retrouver à chaque diagnostic, par exemple cinq lignes :
Constat, Récurrence, Qualité, Procédure, Recommandation.
